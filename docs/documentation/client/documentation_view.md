## Overview {#overview} 

**Documentation** <span className="badge badge--success">NEW</span>: New section designed to centralize all your workflow information. Located in the Data & Information menu, this view provides a complete overview of all processes on your platform. 

<img alt="documentation view" className="img_sizing item shadow--tl" src={useBaseUrl('img/documentation_view_00.png')} />
<br/>

## Quick Access to Key Information {#quick-access}

This new view allows you to:

- **Intuitive Navigation**: View a complete list of all workflows with their name and description
- **Detailed Workflow Summary**: When selecting any flow, access a summary view that includes essential data such as:
  - State diagram
  - Workflow name and description
  - Associated start form
  - Permissions linked to that form
