Previously, automations within forms executed automatically upon completion. With OnPlay, this changes completely. Now you can configure a special button within a form that, when pressed, executes specific code or automation.

**A Button with Multiple Options:**
- **Visual Customization**: Choose the button's label and style to match your form's aesthetic
- **Loading Indicator**: If the automation is asynchronous, the button will display a visual loading indicator to show the process is running
- **Cooldown Time**: Configure the waiting time before the button can be used again
